# Artefacts

Files your agents wrote, and files you attached to threads, across the whole realm (or one agent,
on their Artefacts tab).

Each row: the file, whose thread it came from and which thread, whether it was an *input* (you gave
it) or an *output* (an agent made it), its type, where it is, and when it was last touched.

## Things you'll do

- **Open** a file with its usual program. Files that could run code (`.exe`, `.bat`, `.ps1`, `.py`,
  …) are shown in their folder instead of opened.
- **Show in folder.**
- **Delete** a file you don't need. ARMADA only deletes files inside the realm, its workspace, or
  the ARMADA folder.
- **Filter** by owner, type or date, or search by name, path or thread.

Agents are asked to put what they make for you in the realm's `shared` folder; a file written
elsewhere is still listed, and the thread says where it went.
