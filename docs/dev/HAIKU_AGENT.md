# Small-scope engineering tasks

This historical filename is retained for existing links. Contributors may use any
suitable engine; ARMADA itself supports Claude, Codex and Gemini independently.

Keep a task focused, read the relevant application contracts, use synthetic test
fixtures and verify behavior with the appropriate tests. Escalate unclear product
choices to the maintainer. Do not weaken tests to make a change pass, modify live
user realms as a shortcut, or treat a provider-specific assumption as a shared contract.

Use [the contributor guide](../../CLAUDE.md) and [release procedure](RELEASING.md).
