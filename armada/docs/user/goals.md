# Goals

What the realm is working towards. Every goal's description loads into its owners' context, so an
agent always knows what it's for.

## A goal has

- a **title** and a **description** — be concrete: numbers, dates, what "done" means;
- a **status**: *Not started*, *On track*, *At risk*, *Blocked*, *Done*;
- a **target date** (ETA). A goal past its ETA shows as *At risk*;
- **owners** — the coordinator always owns every goal; drag other agents from the right-hand list
  onto a goal to add them.

## Things you'll do

- **Add a goal:** **+ Add goal**.
- **Edit or delete:** the pencil and bin on the goal.
- **Change owners:** drag an agent onto the goal; the × on an owner chip removes them.
- **Find one:** the search box filters by title and description.
