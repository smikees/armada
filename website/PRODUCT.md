## Platform

## Stack
Implemented local static HTML/CSS preview, intended for the user's existing explicit-FTPS hosting.
the maintainer approved the UI and publication on 2026-10-03; the page is live at https://armada.stamih.com.

## Users and purpose
People evaluating or downloading ARMADA, a Windows desktop application for a standing team
of AI agents. The site must explain the app plainly, provide the installer and link to the
GitHub repository. the maintainer requested a professional presentation that does not feel like sales.

## Capabilities and constraints
ARMADA supports Claude Code, Codex CLI and Gemini through Antigravity CLI, with saved provider
sign-ins. Agent roles, memories, goals, scheduled jobs and artifacts live in local realm folders.
Model requests use remote providers. Provider access and connector authorizations differ.
Windows beta; source-available under PolyForm Noncommercial 1.0.0. The installer is not yet
Authenticode-signed. Do not claim fully offline execution or unrestricted open-source licensing.

## Brand commitments
ARMADA name and exact supplied SVG logo and symbol only; preserve their artwork and proportions.
Exact tagline: “Create, empower and control your army of agents.” Use the app's established
blue/teal accents and Barlow typography. No pricing plans, testimonials, invented performance
claims or sales language. The site should remain simple and professional.

## Evidence
App source and user documentation in the parent repository; release artifacts on
https://github.com/smikees/armada. The user prohibited invented application UI and synthetic
demonstration data. The current page uses text and official branding only. Any future application
imagery must use real screenshots with permission to expose the content. Do not publish private
realm content. ASSETS.md records the supplied originals and their byte-identical website copies.

## Publication boundary
Target armada.stamih.com. Every new ARMADA version must also be published here; routine release
version and download-link updates are owner-authorized as of 2026-10-10. Follow website/README.md
and verify the public result. Unrelated UI redesigns remain subject to maintainer review. FTP
credentials must never appear in chat, source control, browser scripts or downloadable files.
