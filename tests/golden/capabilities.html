Capability types
Connector — a remote link to an outside service (a broker, Google Drive, Telegram, a data feed). A hosted integration an agent uses to read or send real data.
Extension — a local tool running on this machine (local files, a private script, a developer tool). Like a connector, but it stays on your computer rather than calling out to the cloud.
Skill — a packaged instruction set that teaches an agent a repeatable way of doing something (a house writing style, a review checklist, a workflow).
Plugin — a bundle that brings several skills and connectors together, added as one unit.

Adding one
Adding a capability puts it in Test Realm and ARMADA evaluates it automatically, so you can decide whether to turn it on knowing what it can reach. No new capability can be used by an agent until you have turned it on and given that agent access to it.

Managing capabilities
ARMADA runs on your own Claude. A connector, skill, or plugin has to be added and authorised in Claude first — then it becomes available to your agents here. ARMADA shows what’s wired up and lets you scope it per agent; it doesn’t install or hold credentials itself.

The type (below) is how Claude names things. What actually decides trust is shown on every item as three signals: who made it, whether it runs code on your machine, and what it can touch (files · network · shell · connectors). Expand any item to see where it came from and what a content scan found. Treat a third-party item that runs code like installing an app from the internet.
